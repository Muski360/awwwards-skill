# Evaluation Framework

Use this rubric to review completed work and compare concept directions. Do not predict an award or present an internal review as an official Awwwards score.

## Published Awwwards Lens

Official Awwwards site listings display this Site of the Day weighting:

| Criterion | Weight | Review focus |
|---|---:|---|
| Design | 40% | Art direction, composition, typography, color, imagery, detail, and system coherence |
| Usability | 30% | Orientation, navigation, readability, feedback, control, and task completion |
| Creativity | 20% | Original concept, project-specific expression, and meaningful interaction |
| Content | 10% | Relevance, hierarchy, clarity, media quality, and narrative structure |

Awwwards listings also expose development review categories for Semantics/SEO, Animations/Transitions, Accessibility, WPO, Responsive Design, and Markup/Meta-data.

Treat these categories as connected. A visual concept loses value when users cannot read, navigate, control, or load it.

## Skill-Specific Gates

Apply these gates before calculating a review:

- **Identity gate:** The visual thesis and identity anchors appear in the result.
- **SLOP gate:** Prominent treatments pass the transferability test.
- **Accessibility gate:** Core content and controls work with keyboard input and reduced motion.
- **Performance gate:** Heavy media and effects degrade without breaking the experience.
- **Content gate:** The interface uses real or clearly marked placeholder content and makes no fabricated claims.

Mark the review as blocked when a core route, interaction, or accessibility requirement fails.

## Review Method

1. Capture desktop and mobile evidence.
2. Score each published criterion from 1 to 10.
3. Cite a concrete strength and weakness for each score.
4. Run the skill-specific gates.
5. Prioritize the change that improves the weakest high-weight criterion without harming a gate.

Use the weighted score only to compare iterations of the same project. Do not compare unrelated brands through one aesthetic standard.
