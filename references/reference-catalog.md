# Reference Catalogue

Consult an entry when its mechanism addresses a project question. These seven starting points are not an aesthetic shortlist, preferred stack, or effects checklist. Use [external research](external-references.md) to discover beyond them; verify current source, documentation, compatibility, and terms before adoption.

| Reference | Transferable mechanism | What to inspect before adapting |
| --- | --- | --- |
| [Atelier UI](https://www.atelier-ui.com/en) · [source](https://github.com/whatisjery/atelier-ui) | Responses across type, media, cursors, scrolling, and WebGL. Useful for comparing how a medium behaves. | Select a relevant component, inspect its demo/docs/source, and derive its response from the project's material. Separate component dependencies from shared infrastructure; an idea does not require importing the whole system. |
| [react-fluid-distortion](https://github.com/whatisjery/react-fluid-distortion) | Pointer input becomes a flow field that distorts a material surface through React Three Fiber postprocessing. | Choose affected media, intensity, extent, and settling behavior; keep reading stable. Check renderer/postprocessing compatibility and GPU cost, plus touch, reduced-motion, and unavailable-WebGL alternatives. Compare the alternative version linked from its README rather than assuming identical APIs. |
| [mekuri](https://github.com/FunTechInc/mekuri) | Delayed unmounting and coordinated enter/leave behavior connect outgoing and incoming views. | Inspect router/version fit, interruption, history, scroll restoration, and focus. Its documented Next.js App Router integration uses private router internals; recheck that approach against the target framework. Adapt the continuity relationship rather than the demo choreography. |
| [Cuberto mouse-follower](https://github.com/Cuberto/mouse-follower) | GSAP-based contextual cursor states, text/media feedback, and sticking behavior. | Derive states from real actions. Preserve native pointing, selection, form affordances, and visible keyboard equivalents; check initialization/destruction. Follow the [input guidance](motion-and-implementation.md#input-scrolling-and-cursors) and disable fine-pointer decoration for coarse inputs. |
| [Background image parallax](https://github.com/olivierlarose/background-image-parallax) | Scroll relates image displacement, a clipped viewport, and foreground content. | Inspect `src/components/Section.jsx` and its layout. Derive range, crop, contrast, and proportions from the imagery. Compare native mechanisms and the existing stack before inheriting Next.js/Framer Motion scaffolding; compose static and mobile crops. |
| [OnScrollTextHighlight](https://github.com/codrops/OnScrollTextHighlight) | Scroll-triggered emphasis, character timing, and highlight treatments for editorial cadence. | Inspect the selected `js/effect-*` implementation, markup, and CSS. Distinguish triggered playback from continuous scrubbing. Use actual copy to choose emphasis, preserving text semantics and legible rest states instead of animating everything. |
| [Awwwards side menu](https://github.com/olivierlarose/awwwards-side-menu) | An expanding navigation surface coordinates container movement with sequenced link entrances. | Inspect `src/components/Header` and adapt dimensions, density, reach, and pacing to the information architecture. Review tutorial markup for buttons, working links, expanded state, focus, Escape, and rapid toggling before inheriting its Next.js/Framer Motion setup. |

Use the project's shared visual and motion language rather than combining each demo's recognizable style. Apply the source, licensing, and evidence checks in the research guide to any code or assets considered for reuse.
