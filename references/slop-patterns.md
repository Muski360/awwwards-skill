# SLOP Pattern Catalog

Use this catalog during concept review and final audit. “SLOP” means a visual treatment that imitates current design language without serving this project’s identity, content, or interaction.

## Transferability Test

Imagine replacing the logo and copy with an unrelated brand. Mark the treatment as SLOP when it survives unchanged.

## Patterns and Reformulations

| Pattern | SLOP signal | Reformulate |
|---|---|---|
| Purple or blue gradient | A gradient fills visual emptiness and has no source in the brand | Pull color from product material or imagery; use a flat field, photographed light, or a gradient that models a defined light source |
| Missing identity | The page uses safe type, neutral colors, rounded rectangles, and stock icons | Write a visual thesis; choose identity anchors from audience, history, place, product, or content |
| Glass cards | Blur and translucent panels decorate routine content | Use glass only when layers, depth, or the product metaphor require it; otherwise use typography and spacing |
| Card mosaic | Every section becomes a rounded container | Group content through grid, dividers, whitespace, lists, media, or tables |
| Giant headline | Scale acts as the entire concept | Create a distinct typographic voice through width, rhythm, line breaks, crop, and relation to imagery |
| Blob glow | Soft radial shapes sit behind content without meaning | Replace them with a material, light condition, image, or compositional field tied to the subject |
| Pill soup | Labels, filters, navigation, and CTAs all use capsules | Reserve pills for tags, filters, or compact states; give navigation and actions their own hierarchy |
| Stock abstract 3D | A floating chrome object could advertise any digital product | Model a product form, process, data relationship, or brand artifact; use a still image if interaction adds no value |
| Effect stack | Grain, glow, parallax, tilt, cursor, and marquee compete | Choose one signature motif and one supporting motion behavior |
| Scroll hijacking | The page blocks expected input to stage animation | Keep native scrolling; use sticky scenes or scroll-linked progress with an escape path |
| Custom cursor | A cursor trails, stretches, or hides without improving feedback | Keep the system cursor or change it only to reveal a real interaction state |
| Infinite marquee | Repeated words or logos fill an empty transition | Use a concise proof point, editorial break, or narrative media sequence |
| Fake social proof | Invented logos, awards, metrics, or testimonials create credibility | Use verified evidence or remove the section |
| Decorative grid | A technical grid overlays the background because the product is digital | Let the grid control alignment or encode data; hide it when it serves no function |
| Icon wallpaper | Generic line icons repeat beside every sentence | Use fewer icons, project-specific symbols, numbering, or pure typography |
| Template section order | Hero, logo cloud, card grid, testimonial, pricing, CTA appears by reflex | Build a content spine from the project’s actual decision journey |
| Generic copy | “Redefine the future” and similar claims could describe any company | Name the product, action, audience, constraint, or result |

## Audit Procedure

1. Capture the first viewport and one full-page view at desktop and mobile widths.
2. List the five most noticeable treatments.
3. Run the identity, hierarchy, transferability, and cost tests on each treatment.
4. Remove one treatment that contributes no meaning.
5. Strengthen the clearest identity anchor instead of adding a replacement effect.

## Severity

- **Blocker:** fake evidence, inaccessible interaction, broken mobile layout, unreadable text, or motion that traps input
- **High:** missing identity, generic hero, effect stack, decorative 3D, or content hidden behind spectacle
- **Medium:** excess cards, pills, gradients, blur, icons, or repeated section patterns
- **Low:** inconsistent radii, weak spacing rhythm, minor decorative noise
