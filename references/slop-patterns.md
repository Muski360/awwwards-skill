# SLOP Pattern Catalog

Use this catalog during concept review and visual audits. SLOP is a treatment that imitates current design language without serving the project's identity, content, hierarchy, or interaction.

The catalog supplies diagnostic triggers, not banned ingredients. Keep a gradient, card, pill, marquee, cursor, or 3D scene when project evidence gives it a clear job. A conventional or transferable pattern is not automatically SLOP; it fails when it weakens the established intent, task, hierarchy, or experience.

## Transferability Test

Imagine replacing the logo and copy with an unrelated brand. Treat transferability as a diagnostic signal when the treatment survives unchanged and its stated rationale could describe either project. Confirm that it is actually harming this product before removing it; familiar conventions can be intentional and useful.

## Patterns and Reformulations

| Pattern | SLOP signal | Reformulate |
|---|---|---|
| Purple or blue gradient | A gradient fills visual emptiness and has no source in the brand | Pull color from product material or imagery; use a flat field, photographed light, or a gradient that models a defined light source |
| Missing identity | The page uses safe type, neutral colors, rounded rectangles, and stock icons | Write a visual thesis; choose identity anchors from audience, history, place, product, or content |
| Glass cards | Blur and translucent panels decorate routine content | Use glass when layers, depth, or the product metaphor require it; otherwise use typography and spacing |
| Card mosaic | Every section becomes a rounded container | Group content through grid, dividers, whitespace, lists, media, or tables |
| Giant headline | Scale acts as the entire concept | Create a distinct typographic voice through width, rhythm, line breaks, crop, and relation to imagery |
| Blob glow | Soft radial shapes sit behind content without meaning | Replace them with a material, light condition, image, or compositional field tied to the subject |
| Pill soup | Labels, filters, navigation, and CTAs all use capsules | Reserve pills for tags, filters, or compact states; give navigation and actions their own hierarchy |
| Stock abstract 3D | A floating chrome object could advertise any digital product | Model a product form, process, data relationship, or brand artifact; use a still image if interaction adds no value |
| Effect stack | Grain, glow, parallax, tilt, cursor, and marquee compete | Center the effect on one identity anchor and a supporting motion behavior |
| Information echo | Labels, icons, cards, helper text, and headings repeat the same message | Consolidate the signal; make one element carry the decision or evidence clearly |
| Decorative density | Extra panels, dividers, badges, textures, or controls make a section busy without changing its reading path | Remove or simplify the layers and restore hierarchy through spacing, type, or composition |
| Verbose or formal copy | A simple interface message becomes a marketing essay, abstract claim, or bureaucratic explanation | Keep the subject, action, constraint, or proof; rewrite in the product's actual voice |
| Scroll hijacking | The page blocks expected input to stage animation | Restore expected native behavior; use a sticky scene or scroll-linked progress only when it preserves input and passes the scrolling gate |
| Custom cursor | A cursor trails, stretches, or hides without improving feedback | Keep the system cursor or change it to reveal a real interaction state while preserving normal pointing behavior |
| Infinite marquee | Repeated words or logos fill an empty transition | Use a concise proof point, editorial break, or narrative media sequence |
| Fake social proof | Invented logos, awards, metrics, or testimonials create credibility | Use verified evidence or remove the section |
| Decorative grid | A technical grid overlays the background because the product is digital | Let the grid control alignment or encode data; hide it when it serves no function |
| Icon wallpaper | Generic line icons repeat beside every sentence | Use fewer icons, project-specific symbols, numbering, or pure typography |
| Template section order | Hero, logo cloud, card grid, testimonial, pricing, CTA appears by reflex | Build a content spine from the project's decision journey |
| Generic copy | “Redefine the future” and similar claims could describe any company | Name the product, action, audience, constraint, or verified result |

## Audit Procedure

1. Capture the first viewport and a full-page view at desktop and mobile widths when browser tools are available. Without them, inspect source and assets and label visual conclusions as unverified.
2. List the most noticeable treatments and the intended job of each.
3. Run the identity, hierarchy, transferability, complexity, and cost tests on each treatment.
4. Check whether repeated information, components, copy, or effects obscure a clearer path. Preserve deliberate pacing and detail when they still earn their place.
5. Assign severity only to treatments that fail. In read-only mode, recommend a reformulation; in an authorized edit, remove or reformulate the failures.
6. Strengthen the clearest identity anchor when removal leaves a gap. Do not add a replacement effect by reflex.

## Severity

- **Blocker:** fabricated evidence; a failed core route or task; an inaccessible core control; motion that traps required input; or an effect that removes the only usable content path
- **High:** missing identity, a generic hero, an effect stack, decorative 3D, content hidden behind spectacle, or other accessibility, usability, readability, and responsive gate failures
- **Medium:** excess cards, pills, gradients, blur, icons, or repeated section patterns that weaken hierarchy
- **Low:** inconsistent radii, weak spacing rhythm, or minor decorative noise
