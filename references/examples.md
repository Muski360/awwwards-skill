# SLOP-to-Distinctive Examples

Use these examples as reasoning patterns. Do not copy their art direction into unrelated projects.

## 1. Unmotivated Gradient

**SLOP:** Add a purple-to-blue glow behind a dark hero because the page feels empty.

**Diagnosis:** The color has no source in the product or brand. The glow masks weak composition.

**Reformulation:** For a precision watchmaker, use a near-black field, a macro photograph of brushed steel, and a narrow warm reflection that follows the product’s real material. Use a gradient only to model that reflection.

**Result:** Light describes the object and creates a recognizable material language.

## 2. No Visual Identity

**SLOP:** Use a neutral sans serif, lime CTA, rounded feature cards, and stock line icons for a theatre archive.

**Diagnosis:** The system could serve a software startup with no structural change.

**Reformulation:** Build the archive around compressed playbill typography, ticket-red accents, perforated dividers, cast-list columns, and scene changes that resemble stage curtains.

**Result:** Content, history, and interaction share one identity.

## 3. Default SaaS Card Grid

**SLOP:** Present six product benefits as equal glass cards under a centered headline.

**Diagnosis:** Equal containers flatten priority and make the page read like a template.

**Reformulation:** Give the primary workflow a full-width annotated sequence. Place secondary capabilities in a compact index with dividers. Use one interactive panel only for the feature that requires direct manipulation.

**Result:** The composition reflects product priority and reduces chrome.

## 4. Decorative 3D

**SLOP:** Place a rotating chrome torus in the hero of an accounting product.

**Diagnosis:** The object adds rendering cost but explains nothing about the product.

**Reformulation:** Use a crisp ledger composition where rows reconcile as the user scrolls. Reserve depth for a layered cash-flow model if spatial separation improves understanding.

**Result:** Motion demonstrates the product’s value.

## 5. Motion Stack

**SLOP:** Add smooth scrolling, a custom cursor, magnetic buttons, text splitting, parallax, tilt, and an infinite marquee.

**Diagnosis:** Each effect asks for attention. None owns the experience.

**Reformulation:** For a music label, use one timing system based on the track tempo. Sequence the hero entrance on the beat, connect releases through a restrained vertical scrub, and use a short waveform response on playable items.

**Result:** Motion forms a recognizable grammar tied to the subject.

## 6. Generic Portfolio

**SLOP:** Open with “Creative developer crafting digital experiences,” followed by project cards with identical hover effects.

**Diagnosis:** The claim and layout reveal no point of view.

**Reformulation:** Choose a thesis from the developer’s work, such as procedural typography. Let the hero generate a live typographic specimen, organize projects by the constraint each one solved, and vary case-study composition according to the artifact.

**Result:** The portfolio demonstrates the capability instead of claiming it.

## 7. Empty Premium Styling

**SLOP:** Add beige surfaces, serif headlines, thin rules, and slow fades to make a product feel luxurious.

**Diagnosis:** Luxury appears as a preset rather than a property of the product.

**Reformulation:** For a ceramic studio, derive the palette from clay and glaze, use close crops that show imperfections, set product data like kiln records, and reveal pieces at the pace of physical inspection.

**Result:** The experience earns its tone through material evidence.

## 8. Mobile Afterthought

**SLOP:** Stack desktop sections, disable the 3D canvas, and leave oversized type clipped on mobile.

**Diagnosis:** The mobile page loses both function and identity.

**Reformulation:** Recompose the opening around one tactile image, keep the signature type crop within the viewport, replace spatial navigation with a thumb-friendly sequence, and preserve the core motion with shorter travel.

**Result:** Mobile keeps the same thesis through a different composition.
